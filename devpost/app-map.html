DAVE — App Map

A proof-of-concept agile workflow platform where human teammates work alongside three AI teammates (Michael, Jim, Dwight) on a shared Kanban board, with GitHub integration for branches/PRs and automated code review.

How a Task Flows Through the System

1. Michael reads the GitHub repo file tree → proposes tasks with real file paths → saved to Supabase tasks table.

2. Jim takes a task → creates a branch + PR via GitHub API → branch name and PR URL stored on the task.

3. Dwight reviews the PR by task display ID → produces structured review report → stored in review_reports.

4. Pam answers "has anyone built this?" → searches public GitHub → returns repos with relevance reasons.

Code Route (2-3 stops)

  1. Entry point: app/projects/[id]/page.tsx — the main workspace with the Kanban board.
  2. AI agents: lib/agents/michael.ts, lib/agents/jim.ts, lib/agents/dwight.ts, lib/agents/pam.ts — each agent's prompt and logic.
  3. GitHub integration: lib/github/server.ts — server-side GitHub REST API client.
  4. Data layer: lib/supabase/server.ts — Supabase client for data access.

To Change This, Start Here

  • Add a new agent: create a file in lib/agents/, add an API route in app/api/.
  • Change the Kanban stages: update the stage enum in lib/types/database.ts and the board component.
  • Modify review logic: edit lib/agents/dwight.ts and app/api/dwight/[projectId]/review/route.ts.
  • Change styling: edit Tailwind classes in components; theme config in tailwind.config.

A Practice to Reuse

Decision: Reviewer agent reviews committed code by task display ID instead of running live browser tests.

Evidence: devpost/spec.md > What Was Simplified and Why — deferred Playwright to "Later" per scope.

Practice: When a full implementation is too complex for a POC, identify the kernel (the idea you're proving) and simplify the expression — mock or simulate the non-essential parts while keeping the core behavior real. Label simulations clearly.

How to Run Again

npm run dev → open http://localhost:3000. Requires .env.local with Supabase, OpenAI, and GitHub token keys.
